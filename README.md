# EEA Privacy Working Group Report

Interactive web publication of the Enterprise Ethereum Alliance Privacy Working Group report (March 2026).

## View

Open `privacy-report.html` in any browser — single self-contained file, no dependencies.

## Features

- Dark/light mode toggle
- Sticky sidebar navigation
- Expandable solution cards
- Filterable coverage matrix
- Print stylesheet
- Scroll animations
